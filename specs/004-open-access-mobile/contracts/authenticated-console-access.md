# Authenticated Console Access Contract

## Purpose

定义浏览器控制台与管理 API 的统一访问边界，确保“登录后默认开放”在 UI 与服务端一致生效。

## Preconditions

- 请求必须携带有效的现有访问令牌。
- 当前用户账户必须处于可用状态。
- 改变性请求必须提供业务所需的目标对象或工作范围。

## Guaranteed behavior

| 场景 | 预期结果 |
| --- | --- |
| 任意已登录用户访问 11 个控制台页面 | 正常返回页面所需数据，不根据平台/租户角色拒绝 |
| 任意已登录用户请求已有控制台读写操作 | 按输入和业务规则处理，不返回角色权限错误 |
| 访问全局租户列表、设置、成员、审计或告警 | 对每位已登录用户提供同一能力 |
| 未选工作范围时访问页面 | 页面可打开；涉及具体对象的操作请求选择目标或给出输入错误 |
| 无令牌、无效令牌或已禁用账户 | 拒绝并要求认证；不得返回控制台数据 |
| 目标范围、资源或服务凭据不一致 | 返回现有的业务/完整性错误；不得将其伪装为角色错误 |

## Non-goals

- 不改变外部 Agent API Key 的作用域规则。
- 不允许匿名用户访问控制台 API。
- 不改变资源标识、审计字段或业务输入校验。
