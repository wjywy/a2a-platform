# Mobile Navigation Contract

## Bottom navigation

在手机纵向视图中，控制台展示且只展示以下五项固定底栏：

1. 概览
2. Agent
3. 在线调试
4. 任务
5. 更多

每项有可访问名称、44×44 像素以上有效触控区域、当前状态提示和键盘焦点。底栏本身不横向滚动。

## More panel

“更多”打开后提供：

- 用量、租户、成员、Webhook、告警、审计、平台设置；
- 当前工作范围及全部范围选择；
- 注册 Agent；
- 当前账号信息与退出登录。

选择页面后，面板关闭并更新地址和当前状态。点击遮罩、关闭控件、Escape 与焦点管理均能安全关闭面板。用户通过直接地址进入次级页面时，更多入口须表示该页面属于次级导航。

## Responsive behavior

- 页面内容、弹层、抽屉、确认窗口和在线调试输入区避开系统安全区及底栏。
- 在 320、360、390、430 像素手机宽度、手机横向、平板和桌面上，根文档不出现意外横向滚动。
- 数据密集页面可重排或在局部区域提供明确的滚动/详情路径，但不隐藏关键字段和操作。
- 触摸交互提供按下、加载、成功/失败及适用的禁用状态；不以悬停作为唯一入口。
