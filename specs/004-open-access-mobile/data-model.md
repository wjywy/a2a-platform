# Data Model: 登录即全功能可用与移动控制台重构

本功能不新增持久化表或删除既有角色数据。以下是受行为改变影响的逻辑实体和约束。

## 已登录用户

| 属性 | 说明 | 验证规则 |
| --- | --- | --- |
| 用户标识 | 当前有效会话绑定的用户 | 必须由现有认证流程验证 |
| 账号状态 | 当前账户是否处于可用状态 | 已禁用账户不能访问控制台 |
| 平台角色 | 既有运营身份信息 | 可展示和审计，不能决定控制台能力 |
| 工作范围选择 | 当前查看或操作的租户/全部范围 | 可为空；为空时页面应提供选择路径而非拒绝访问 |

## 工作范围

| 属性 | 说明 | 验证规则 |
| --- | --- | --- |
| 范围标识 | 单个租户或全部范围 | 所有登录用户均可在控制台选择 |
| 显示上下文 | 控制列表、图表、表单默认对象 | 不得作为页面或操作的角色门槛 |
| 操作目标 | 改变性操作实际作用的范围 | 必须存在且与请求中的目标对象一致 |

## 控制台导航项

| 属性 | 说明 | 验证规则 |
| --- | --- | --- |
| 页面键 | 11 个既有控制台页面之一 | 有效会话可通过导航或直接地址打开 |
| 导航分组 | 桌面上的运营/治理分组 | 仅影响信息组织，不能过滤页面 |
| 移动优先级 | 主要或次级 | 四个主要页面在底栏；其余次级页在“更多” |
| 激活状态 | 当前地址对应的页面 | 深链接、浏览器前进后退和菜单状态必须同步 |

## 移动更多面板

| 属性 | 说明 | 验证规则 |
| --- | --- | --- |
| 打开状态 | 面板是否显示 | 关闭后焦点返回触发入口；不遮挡关闭路径 |
| 次级导航 | 七个低频页面 | 每项在不超过两次导航点击内可达 |
| 全局操作 | 范围选择、注册 Agent、账号、退出 | 每项具备名称、触摸和键盘可达路径 |
| 安全区域 | 系统底部与固定导航占用的区域 | 面板、页面和输入区不得与其重叠 |

## 操作审计记录

既有审计记录继续包含操作者、时间、目标范围、资源和结果。改变访问策略不能省略、伪造或覆盖这些字段；角色变更、租户变更及 API 密钥等既有业务操作仍记录实际操作者。
